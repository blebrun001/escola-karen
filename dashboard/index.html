Com s’obtenen les dades?

El sistema consulta cada dia les pàgines oficials dels serveis territorials, analitza els PDF publicats i compara la seva empremta digital amb la verificació anterior.

Una oferta es destaca només quan el codi d’especialitat és exactament GE o CLA. Un PDF buit no es considera un error d’extracció.
